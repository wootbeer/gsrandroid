Golden Sun Recompiled for Android
=====================

Based on [Golden Sun Recompiled](https://github.com/Shmargus/GSRecomp). ty. Brought to Android with my Descore framework.  

**Noncommercial, free forever. This app contains no Golden Sun code, ROM or assets.**  

Plays Golden Sun and Golden Sun: The Lost Age, with your party carried over from the first game to the second.

Added various rendering and quality of life features.  

You will need the game files from licensed copies in order to play them.  

Game Files
-------
Make sure to have 800mb free on your device for processing each game.  
Place files onto your device in an accessible folder.  

Your own legally obtained Golden Sun and/or Golden Sun: The Lost Age GBA ROMs. Supported versions (SHA-1):

On first launch the app will ask you to select the files. Each game and language is recognised whatever its file name, and shows up in the launcher once added. If it closes or errors you are not using the correct version of the file.  
Every language has its own game build, save and save states. A language's Saves page can copy over your USA/Europe save.  
The first time you play each game it translates and compiles the game code on your device, into the app's storage. Depending on your device this will take 2-10 minutes per game.  
After an app update this happens once more.  

Controls
-------
Auto show/hide on-screen touch controls.  
Optimized for handhelds.  
The controls can be remapped in-game side menu.  
To access the side menu hit the menu key for touch users, or click right-stick (R3), or hit the Back button.  
Fast-forward default is right-trigger, can be changed.  

Android Handhelds / Retroid Devices:  
Make sure controller style is set to Retro or whatever your devices default is. Ntndo style as opposed to Xbox style, swipe down menu to access these options.  

Features
-------
- Golden Sun: The Lost Age in the same app.  
- Spanish, Italian, French and German versions of both games, each with its own save.  
- Option to start your last game straight away, and Switch game in the menu.  
- Party transfer: on a new Lost Age game, "Load a Golden Sun save file?" uses the Golden Sun save in the app or a .sav file you pick.  
- Seamless mode: finish Golden Sun and continue straight into The Lost Age (asked when starting a new Golden Sun game, once The Lost Age is installed).  
- Saves page: export and import .sav files (GBA emulators, flash carts), undo an import, and back up both games' saves to a folder of your choice.  
- Renderer choice: Auto, CPU or GPU (experimental). Auto uses the CPU for Golden Sun and the GPU for The Lost Age in Expanded view.  
- Touch layout editor: drag the on-screen controls where you want them.  
- Portrait mode for phones (Settings > Display > Orientation), with the controls spread out, compact under the picture, or compact at the bottom.  
- Side menu for settings: view mode, scaling, filter, fast forward, frame interpolation, etc.  
- Screen filters  
- Save states  
- Cheats menu.  
- Auto show/hide on-screen touch controls with adjustable size and opacity, plus controller support with button remapping.
